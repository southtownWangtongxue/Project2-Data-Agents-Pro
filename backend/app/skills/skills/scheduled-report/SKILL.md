# 定时报表

## 使用说明
通过 cron 表达式定义报表的执行周期，在指定时间自动执行 SQL 查询并将结果推送至企业微信或邮件。

## 参数
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| name | string | 是 | - | 报表任务名称 |
| sql | string | 是 | - | 要执行的 SQL 查询语句 |
| cron | string | 是 | - | cron 表达式，如 "0 9 * * *" 表示每天9点 |
| channel | string | 否 | wechat | 推送渠道: wechat / email |
| recipients | list | 否 | [] | 推送目标列表（webhook地址或邮箱） |

## 示例
- "每天早上9点发送昨日销售汇总到企业微信"
- "每周一上午10点推送上周库存周报到邮箱"
- "创建一个定时任务：每小时检查一次系统状态并通知我"
- "查看当前所有定时报表任务"

## 准则
- cron 表达式为标准 5 字段格式: 分 时 日 月 周
- 报表执行的 SQL 必须经过 Security Agent 审核
- 每个任务需持久化到数据库，支持启停
- 推送失败时记录错误日志但不影响下次执行
