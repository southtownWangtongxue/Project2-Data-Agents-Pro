## 修复 SSE 流式卡死 Bug：wait_for(__anext__()) 破坏生成器状态 (2026-06-25 PM3)

### 问题
"统计各表数据量" 查询：前端只收到 `thread_id` 事件，后续所有节点事件（clarifier/planner/sql_coder 等）全部丢失，前端一直显示"对话中"。

### 根因
`chat.py` 第 251-254 行：
```python
event = await _asyncio.wait_for(graph_gen.__anext__(), timeout=0.05)
```
`asyncio.wait_for()` 超时后会**取消**内部的 `__anext__()` 协程，破坏了 async generator 内部状态。LLM 节点执行时间远超 50ms，导致 `__anext__()` 每次都被取消，生成器彻底卡死。

### 修复
替换为标准 `async for` 循环，由事件循环自然调度，不设超时：
```python
async for event in graph.astream(initial_state, config, stream_mode="updates"):
    # 排空 stream_queue 中的实时 token
    # 处理节点事件...
```

### 验证
Chrome MCP 自动化测试验证：修复后 clarifier → planner → schema_agent → sql_coder → security → execute_sql → analyst → finish 完整链路正常推送。

## Analyst 实时流式优化 (2026-06-25 PM6)
