### 关键事实备忘
- 后端依赖管理用 uv；pyproject 里 `[tool.uv.index]` 默认指向清华源 `https://pypi.tuna.tsinghua.edu.cn/simple`（海外构建可能慢，可在 Dockerfile 用 `UV_DEFAULT_INDEX` 覆盖）。
- 后端入口 `app.main:main` 里 `uvicorn.run(..., reload=True)` 仅限本地开发；容器/生产用 `uv run uvicorn app.main:app --host 0.0.0.0 --port 8000`（无 reload）。
- 后端配置双轨：`backend/configs/*.json`（ConfigManager 热加载：llm_providers/skills/mcp_servers/default）+ `.env`（pydantic-settings：MySQL/PG/Redis/Milvus/LLM 连接）。
- 前端构建：`npm run build` = `vue-tsc && vite build`，产物 `dist/`。
