## Bug 修复（13:49 — 14:00）

### Bug 1: Suggestions API 超时
- 根因: axios 默认 30s 超时，后端连接业务 DB 时可能挂起
- 前端 (`chat.ts`): 请求超时降为 8s，超时后使用硬编码默认模板
- 后端 (`chat.py`): `get_table_schemas` 加 `asyncio.wait_for(timeout=8.0)`，超时/异常时返回默认建议（不再抛 HTTP 500）

### Bug 2: 历史会话加载空消息
- 根因: `PlainRedisSaver._load_from_redis()` 的 key 解析 bug。Thread ID 格式 `admin:uuid` 含冒号，但 `split(":", 2)` 把冒号错误分割
- 修复 (`redis_saver.py`): 新增 `_parse_ckpt_key()` 方法，兼容 4 段格式（username:uuid:ns:ckpt_id）和 3 段旧格式
- 需要重启后端生效

### Bug 3: analyst_node NameError
- 根因: 旧代码 `logger.info(... insights, anomalies)` 引用已删除的变量
- 修复 (`workflow.py`): 日志改为 `len(analysis_text)` 和 `dynamic_chart_suitable`

- sql_coder 节点: 移除 tool_call/tool_result（SQL 由格式化卡片展示）

- rag_agent 节点: 同上

**3. `chat.ts`**:
