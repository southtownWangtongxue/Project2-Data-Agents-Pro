## PUT/DELETE 405 错误修复

### 根因分析
1. **数据问题**：`configs/llm_providers.json` 中第二个 provider 的 `id: ""` 为空字符串
2. **前端 URL 拼接**：`${p.id}` 为空时生成 `/config/llm/` → FastAPI 307 重定向 → `/config/llm` 无 PUT 路由 → 405
3. **路由重复注册**：`main.py` 通过 `v1_router` 和直接注册两次 `config_router`

### 修改文件
| 文件 | 修改内容 |
|------|----------|
| `backend/configs/llm_providers.json` | 空 id 改为 `qwen-flash`，同时修正 api_base 和 api_key_env |
| `backend/app/main.py` | 移除 config/knowledge/schedule router 的重复注册 |
| `backend/app/api/v1/__init__.py` | 补充 knowledge_router + schedule_router 的 include |
| `frontend/src/views/admin/LlmConfig.vue` | save/remove/toggleEnabled 添加空 ID 防护 |
| `backend/app/api/v1/config_api.py` | POST 创建时校验 id 不为空 |

### 验证结果
- Chrome DevTools 网络请求确认：`PUT /config/llm/qwen-flash [200]` ✅
- 编辑弹窗保存正常关闭，无错误提示
