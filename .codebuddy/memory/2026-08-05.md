## 字体冲突根因修复（2026-08-05 深夜，浏览器验证通过）

### 用户反馈 3 个问题
1. 信息列表/输入框/思维链字体与背景冲突看不清
2. 输入框和信息框未占满右侧
3. 问题模板白底与整体 UI 不符

### 根因（关键！）
- **`XProvider` 未传 `theme`** → ant-design-x-vue 内部组件使用 antdv **默认浅色 token**（如 Prompts 背景 `rgb(255,255,255)` 纯白 + 白字 0.88 → 白底白字不可见）。仅改 CSS 变量不够，必须通过 `XProvider :theme` 启用暗色算法。
- 实测证据：`promptBg: rgb(255,255,255)`, `promptColor: rgba(255,255,255,0.88)` → 白底白字。

### 修复
1. **`ChatXVue.vue`**：`XProvider` 传入 `:theme="{ algorithm: theme.darkAlgorithm, token: { colorPrimary:'#7056f8', colorBgBase:'#0a0a0a', colorBgContainer:'#0f0f11', colorBgElevated:'#1a1a1d', colorText:'rgba(255,255,255,0.88)', ... } }"`（`theme` 从 `ant-design-vue` 导入）。→ X 组件全局暗色。
2. **占满右侧**：`XBubbleList` padding 改 `32px 32px 24px`（去 `calc((100%-700px)/2)` 居中）；`XSender` 去 `max-width:700px; margin:0 auto`，改 `padding: 12px 32px 20px`。→ 实测 `senderWidth: 1640px` 全宽。
3. **`XWelcome.vue`**：Prompts 样式选择器改为**实际类名 `ant-prompts-item`**（不是 `ant-x-prompts-item`），加 `!important` 覆盖渐变 `linear-gradient(123deg,#1e2a38,#2b1f3b)` 与白字。→ 实测渐变生效。

### 验证
- 暗色 token 全局生效：Bubble `rgba(255,255,255,.03)` 底 + 白字 0.85/0.88；ThoughtChain 标题白字 0.88；textarea 白字 0.88；Prompts 渐变卡。
- 截图：`docs/plans/d3-darktheme-fullwidth.png`；`vue-tsc` 通过；旧 `/chat` 回归正常。
- **教训**：接入 ant-design-x-vue 时，`XProvider` 必须显式配置 `theme`（含 darkAlgorithm），否则组件内部用浅色 token 与深色页面冲突。
