## Redis 检查点修复：PlainRedisSaver 替代 AsyncRedisSaver (2026-06-16 17:11)

### 问题
`AsyncRedisSaver` 依赖 RediSearch 模块 (`FT._LIST` / `FT.CREATE` 命令)，用户 Redis (10.50.56.41:6389) 未安装该模块，导致每次启动回退到 MemorySaver。

### 解决方案
新增 `backend/app/graph/redis_saver.py` — `PlainRedisSaver(InMemorySaver)`：
- 继承 InMemorySaver 获得完整 LangGraph 检查点逻辑
- 写入时同步到 Redis (纯 String/ZSET，无需任何模块)
- 启动时从 Redis 加载历史检查点（带 5s SCAN 超时保护）
- 支持 `adelete_thread` 物理删除
- `chat.py` sessions API 自然继承 `alist()`/`aget()` 方法

### 修改文件
| 文件 | 变更 |
|------|------|
| `backend/app/graph/redis_saver.py` | **新增** PlainRedisSaver + Redis JSON 持久化 + blob 恢复 |
| `backend/app/graph/workflow.py` | `init_checkpointer()` 改用 PlainRedisSaver，移除 AsyncRedisSaver 依赖 |

### 验证

- Graph 编译: `CompiledStateGraph`, Checkpointer: `PlainRedisSaver`
