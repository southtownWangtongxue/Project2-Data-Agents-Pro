## 十、测试环境限制说明

| 限制 | 影响 | 处置 |
|------|------|------|
| 系统仅存在 `admin` 一个账号 | RBAC 差异、审批职责分离无法端到端验证 | 相关用例标注「阻塞」，改为代码审查 |
| DashScope 免费额度已耗尽 | 默认路由下 LLM 调用 403，正文生成类用例降级 | 显式指定可用 provider 后复测通过，单独记录路由缺陷 |
| 事件溯源 `EVENT_SOURCING_ENABLED` 默认关闭 | 轨迹/导出类用例返回空或 404 | 记录为配置类缺陷 |
| MCP 无可用 Server 且 `npx` 不在 PATH | 连接测试无法真连 | 仅验证接口契约与错误处理 |
