# DataAgent Pro 前端重新设计方案

## 设计理念

基于 **Apple 设计风格 + 深色科技感** 重新设计 DataAgent Pro 前端。

### 设计原则

1. **极简留白** - 大量留白，内容聚焦，减少视觉噪音
2. **高端质感** - 微妙的边框、柔和的阴影、渐变色点缀
3. **清晰层级** - 明显的视觉层次，易于理解和操作
4. **优雅动效** - 微妙的过渡动画，提升用户体验

## 配色方案

### 主色调

| 颜色 | 色值 | 用途 |
|------|------|------|
| Primary | `#6366f1` (靛蓝) | 按钮、链接、强调 |
| Primary Light | `#818cf8` | 悬停状态 |
| Primary Dark | `#4f46e5` | 按下状态 |

### 背景色

| 颜色 | 色值 | 用途 |
|------|------|------|
| Background | `#09090b` | 页面背景（纯黑） |
| Surface | `#18181b` | 卡片、面板 |
| Surface Elevated | `#27272a` | 输入框、次级面板 |

### 文字色

| 颜色 | 色值 | 用途 |
|------|------|------|
| Text Primary | `#fafafa` | 主标题、按钮文字 |
| Text Secondary | `#a1a1aa` | 正文、描述 |
| Text Muted | `#71717a` | 占位符、次要信息 |

### 状态色

| 颜色 | 色值 | 用途 |
|------|------|------|
| Success | `#22c55e` | 成功状态 |
| Warning | `#f59e0b` | 警告状态 |
| Error | `#ef4444` | 错误状态 |

## 字体方案

| 用途 | 字体 | 特点 |
|------|------|------|
| 标题/正文 | Inter | 现代、无衬线、科技感 |

## 组件更新

### 1. App.vue - 导航栏

**改进点：**
- 添加 Logo 图形（渐变背景 + 数据图标）
- 标题使用渐变色文字
- 导航链接添加图标
- 毛玻璃效果背景
- 悬停和激活状态使用主题色

### 2. Home.vue - 首页

**改进点：**
- Hero 区域采用左右布局
- 标题使用渐变色
- 添加动画徽章
- 功能卡片使用渐变图标背景
- 添加模拟数据查询可视化卡片
- 浮动动画元素

### 3. Chat.vue - 聊天页

**改进点：**
- 空状态添加插画和快捷建议
- 用户消息使用渐变背景
- 助手消息使用深色卡片
- SQL 代码块使用深色背景
- 输入框采用圆角胶囊设计
- 发送按钮使用渐变色

### 4. Approval.vue - 审批页

**改进点：**
- 使用卡片式任务列表
- 添加统计数据展示
- 状态标签使用彩色圆点
- 操作按钮使用语义化颜色
- 空状态添加成功图标

## 预览方式

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173 查看效果。

---

## 注意事项

1. **Element Plus 主题覆盖**：部分样式需要覆盖 Element Plus 默认变量
2. **字体加载**：需要确保 Google Fonts 的 Inter 和 JetBrains Mono 正确加载
3. **响应式设计**：已添加媒体查询支持移动端适配
